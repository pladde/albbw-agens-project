Diese Branch ist für die Fahrradwerkstatt.

Hier entsteht aufgrund von Cleancode eine komplette Neuentwicklung meines Projektes damit ich alle Learnings umsetzen kann


## Installieren der Abhängigkeiten: ##

### 1. Frontend einrichten
Navigiere in den Frontend-Ordner und installiere die Pakete:
```bash
cd frontend
npm install
```

### 2. Backend einrichten
Navigiere in den Backend-Ordner und installiere die Pakete:
```bash
cd backend
npm install
```
